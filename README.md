## <samp>02 &nbsp;·&nbsp; CURRENTLY BUILDING</samp>

<h3 align="center"><a href="https://github.com/kitasid/wave-field-llm">wave-field-llm</a></h3>

<p align="center">
  <a href="https://github.com/kitasid/wave-field-llm"><img src="https://img.shields.io/github/languages/top/kitasid/wave-field-llm?style=for-the-badge&color=6C5CE7&labelColor=0D1117" /></a>
  <a href="https://github.com/kitasid/wave-field-llm"><img src="https://img.shields.io/github/last-commit/kitasid/wave-field-llm?style=for-the-badge&color=6C5CE7&labelColor=0D1117" /></a>
</p>

<p align="center">
  A language model architecture that replaces <b>O(n²) self-attention</b> with wave equation
  dynamics, giving <b>O(n log n)</b> sequence mixing.<br />
  Long context that doesn't get quadratically more expensive the longer you make it — token
  interaction as a field propagating through a medium, rather than an all-pairs comparison.
</p>
